Задание 2 · Канбан-доска

Вариант A: страница строится из массива объектов.

Что требовалось

  • ≥10 объектов с id и 4+ свойствами разных типов, в HTML только пустые контейнеры
  • Одна функция render(), вызывается после каждого изменения
  • Поиск/фильтр с сообщением «ничего не найдено»
  • Действие, заблокированное правилом, с причиной
  • Своя петля для расчёта; делегирование событий

Что мы сделали

  • 12 карточек, 3 колонки, лимит «In progress» = 3
  • Поиск, фильтр по тегу, сортировка по приоритету, прогресс-бар
  • Петли: countByStatus, hoursLeft, getTags

Вопросы на защите

Почему сначала меняем массив, а потом render()?
Страница всегда показывает текущие данные: единственный источник правды: массив.
Что такое делегирование?
Один слушатель на #board вместо кнопки на каждой карточке; closest находит кнопку, dataset.id даёт id.
Как работает блокировка?
В moveCard проверка countByStatus("doing") >= WIP_LIMIT → сообщение и return.
