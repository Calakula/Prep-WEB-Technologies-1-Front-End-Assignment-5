Основы с нуля

Если ты вообще не кодил: вот все понятия, которые встречаются в проекте.

Переменная

Коробка с именем. const x = 5: нельзя переназначить. let y = 1: можно менять.

Функция

Набор команд с именем: function hit(){...}. Вызов: hit().

Массив

Список: [10, 20, 30]. Первый элемент a[0], длина a.length.

Объект

Карточка со свойствами: { id: 1, title: "Write README" }. Доступ: card.title.

Условие if

if (a === b) проверяет равенство без приведения типов. && «и», || «или», ! «не».

Цикл for…of

for (const card of cards) {...}: пройти по каждому элементу массива.

DOM

Страница как дерево объектов. document.getElementById("x") достаёт элемент, el.textContent = "..." меняет текст.

Событие

Реакция на действие: btn.addEventListener("click", функция). Функция выполнится при клике.

render()

Функция, которая стирает и заново рисует страницу по данным. Меняешь данные → зовёшь render().

Делегирование

Один слушатель на родителе вместо десятков на кнопках. e.target.closest("button") находит нажатую кнопку.

Валидация

Проверка данных формы. setCustomValidity("текст") помечает поле как неверное.

Math.random()

Число от 0 до 1 (1 не включая). Формула целого: Math.floor(Math.random()*(max-min+1))+min.
